# Portafolio — Ezequiel Ayala

Portafolio personal sencillo y moderno hecho con HTML, CSS y JavaScript.

## Estructura

- `index.html` — página principal.
- `style.css` — estilos del portafolio.
- `script.js` — pequeñas interacciones.
- `sistema-solar.html` — proyecto 2D.
- `sistema-solar-3d.html` — proyecto 3D.
- `propuesta-novios.html` — proyecto interactivo.

## Publicarlo en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta manteniendo los nombres.
3. En **Settings → Pages**, selecciona la rama principal y la carpeta `/root`.
4. Guarda y espera a que GitHub Pages publique el sitio.
